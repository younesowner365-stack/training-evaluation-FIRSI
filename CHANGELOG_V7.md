# FIRSI V7 - Dashboard décisionnel

- PDF transformé en tableau de bord décisionnel paysage sur 2 pages, avec logo FIRSI/UM6P, KPI cards et graphiques visuels.
- Type de formation optionnel lors de la création d'une session.
- Si le type est défini par RH/Admin, il est affiché verrouillé dans le questionnaire et devient la valeur de référence.
- Si le type n'est pas défini, le collaborateur le choisit dans le questionnaire.
- Répartition par type calculée sur les évaluations, avec distinction de la source : Session / Collaborateur / Non renseigné.
- Export Excel enrichi avec le type retenu et sa source.
- Refonte visuelle globale inspirée des interfaces de pilotage Power BI : navigation, cartes, formulaires, tableaux et espace d'évaluation.
- Aucune ventilation par département dans la synthèse exécutive.
